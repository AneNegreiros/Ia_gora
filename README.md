> Um ecossistema de segurança digital para acolher mulheres em situação de vulnerabilidade ou violência doméstica — preenchendo a lacuna entre a percepção do abuso e a denúncia formal.

---

## 📖 O Problema

| Dado | Contexto |
|------|----------|
| 🌍 1 em cada 3 mulheres no mundo sofre violência doméstica ao longo da vida | Organização Mundial da Saúde |
| 🤐 Apenas **10%** das mulheres em situação de violência buscam ajuda em canais oficiais no Brasil | Lacuna crítica de acolhimento |
| 🚧 Apps oficiais (ex: SP Mulher Segura) exigem medida protetiva prévia | IAgora atende quem ainda está **na fase de dúvida** |

O IAgora existe para quem ainda não possui registro formal, não se reconhece como vítima, ou simplesmente precisa de um lugar seguro para começar.

---

## 🚀 Funcionalidades

### 🤖 Agente IA de Acolhimento
Chatbot by **Gemini API** para tirar dúvidas sobre direitos, identificar sinais de abuso e oferecer suporte emocional com linguagem acolhedora.

### 🫂 Comunidade Anônima
Feed seguro para compartilhamento de relatos e suporte mútuo — **sem exposição de dados pessoais**, usando autenticação anônima do Firebase.

### 🚨 Protocolo de Emergência
Dois mecanismos de proteção em situações de risco:

- **Modo Camaleão** — O app se disfarça como uma ferramenta inofensiva (calculadora ou previsão do tempo) para evitar suspeitas de uso.
- **Frase de Pânico** — Um gatilho de voz ativa alertas silenciosos, inicia gravação de áudio e envia localização em tempo real para contatos de confiança.

## ⚙️ Instalação e Execução

**Pré-requisito:** Node.js instalado.

```bash
# 1. Clone o repositório
git clone https://github.com/brulprado/Ia_gora.git

# 2. Acesse o diretório
cd Ia_gora

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
```

Acesse em: `http://localhost:5173`
